# 🛍️ Retail Sales Analysis | Python + Power BI

This project analyzes retail sales performance using **Python** for data cleaning and **Power BI** for interactive visualization and insights.

---

## 📊 Project Overview
The goal of this project is to understand customer behavior, identify sales trends, and uncover actionable business insights.

**Key Objectives:**
- Clean and explore raw retail sales data using Python.
- Build an interactive Power BI dashboard.
- Generate insights to improve customer retention and marketing strategies.

---

## 🧠 Tech Stack
- **Python:** pandas, numpy, matplotlib, seaborn
- **Power BI:** DAX,dashboard design

---

## 🔍 Key Insights
- Total Revenue: **$456K**
- Orders: **1K**
- Customers: **1K**
- Top Product Categories: Electronics, Clothing, Beauty (almost equal revenue share)
- Customer Age: 34–51 most active
- Gender: Balanced sales between male and female customers

---

## 💡 Recommendations
- Target marketing campaigns for customers aged **18–35**.
- Offer discounts during slow sales periods.
- Track customer retention rate to improve loyalty.
